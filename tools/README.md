# 작업 도구 백업

작업 공간이 비워져도 바로 복구할 수 있게 둔 도구 모음. 비밀값 없음.

- `cards/render_set.js` 카드 6장 렌더링: `node tools/cards/render_set.js 스펙.json`
- `preview/build_page.py` 휴대폰용 미리보기 페이지: `python3 tools/preview/build_page.py queue 출력폴더 "제목"`
- `preview/make_preview.py` 한 장짜리 미리보기 이미지
- `preview/photo_sheet.py` 사진 후보 모아보기: `python3 tools/preview/photo_sheet.py "폴더/*.jpg" 결과.jpg`
- `reels/` 릴스 영상 도구 (현재 보류)
- `작업지침서.txt` 소재 고르기~본문 작성 규칙
